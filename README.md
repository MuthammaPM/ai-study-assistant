# ai-study-assistant
A Python-based AI study Assistant powered by Gemini API.
Features

- AI Chat: Ask questions and get explanations in simple language.
- Notes Summarizer: Summarize study notes from text files.
- Code Explainer: Understand code through beginner-friendly explanations.

Technologies Used

- Python
- Google Gemini API
- Google Gen AI Python SDK

Setup Instructions

Install dependencies

pip install -U google-genai

Set your API key

On Windows Command Prompt:

set GEMINI_API_KEY=your_api_key_here
set GEMINI_MODEL=gemini-3.5-flash-lite

Replace "your_api_key_here" with your own API key. Never publish your real key.

Run the project

python ai_assistant.py

Project Structure

- "ai_assistant.py" — Main application code
- "README.md" — Project documentation
